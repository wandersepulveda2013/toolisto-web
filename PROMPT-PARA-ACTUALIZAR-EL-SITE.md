# Instrucción para actualizar el Site actual de Toolisto

Reemplaza la portada actual por una experiencia directa y funcional. Conserva las seis herramientas y todo el procesamiento local que ya funciona.

## Principio del rediseño

Toolisto debe sentirse como una aplicación real, no como una landing page creada para promocionar una idea. El usuario debe poder subir un archivo inmediatamente y ver las herramientas sin recorrer demostraciones, beneficios repetidos o secciones decorativas.

## Portada

1. Encabezado blanco y compacto con:
   - logotipo Toolisto;
   - Imágenes;
   - PDF;
   - Firmas;
   - Todas las herramientas;
   - buscador y selector de tema.

2. Título principal:

   **¿Qué quieres hacer con tu archivo?**

3. Texto breve:

   **Sube una imagen o un PDF. Toolisto detectará el formato y te mostrará una acción compatible.**

4. Zona real para arrastrar, pegar o seleccionar archivos. No utilizar imágenes, nombres de archivo ni demostraciones ficticias.

5. Después de seleccionar un archivo, mostrar:
   - nombre, formato y peso;
   - acción recomendada;
   - opción para elegir otra herramienta;
   - ajustes avanzados cerrados;
   - botón Procesar archivo.

6. Inmediatamente debajo, mostrar:
   - título «Elige y empieza»;
   - buscador;
   - filtros Todas, Imágenes, PDF y Firmas;
   - tarjetas compactas de las seis herramientas.

## Tarjetas

Las tarjetas deben ser completamente pulsables y contener únicamente:

- icono propio;
- nombre;
- descripción de una línea;
- flecha discreta.

No usar «Abrir herramienta», párrafos extensos ni tarjetas exageradamente altas.

## Identidad visual

- Fondo crema o gris cálido muy claro.
- Superficies blancas.
- Texto grafito.
- Naranja como color principal.
- Azul, verde, morado, rojo y amarillo para diferenciar herramientas.
- Logotipo abstracto formado por tres piezas de color.
- Bordes finos y sombras moderadas.
- Esquinas redondeadas sin exageración.
- Animaciones únicamente al arrastrar, pulsar, procesar y finalizar.
- Tema oscuro opcional.

## Eliminar

- La demostración con `foto-solicitud.jpg`.
- «Selecciona → Ajusta → Listo».
- Frases promocionales repetitivas.
- Insignias de beneficios.
- Bloques largos sobre privacidad en la portada.
- Fondos futuristas, luces difusas y gradientes exagerados.
- Sección de explicación visual ficticia.

## Privacidad

Mostrar solamente una franja breve al final:

**Tus archivos se quedan contigo. Las herramientas actuales trabajan dentro del navegador. Toolisto no almacena el contenido que procesas.**

La explicación completa puede permanecer en la página de privacidad.

Usa como referencia exacta los archivos `index.html`, `styles.css` y `app.js` incluidos en el paquete.
